# Adhithya — Personal Portfolio

A responsive personal portfolio website built with **HTML, CSS, and JavaScript**. It showcases my projects, education, technical skills, and contact information as a Computer Science and Engineering student at **SRM Institute of Science and Technology**.

[View Repository](https://github.com/adhithyaa07/Adhithya-Portfolio)

## Features

- Responsive layout for desktop, tablet, and mobile screens.
- Light and dark modes with a saved theme preference.
- About Me and Education sections.
- Project cards with descriptions, technology tags, and relevant source code or demo links.
- Technical skills grouped by languages, frameworks, databases, concepts, and tools.
- Downloadable résumé and links to email, GitHub, and LinkedIn.

## Run Locally

The portfolio is a static website. It does not require npm packages, a build step, a database, or API keys.

1. Clone the repository, or download and extract its ZIP archive.

   ```bash
   git clone https://github.com/adhithyaa07/Adhithya-Portfolio.git
   cd Adhithya-Portfolio
   ```

2. Open `index.html` in a web browser.

   Alternatively, if Python is installed, start a local server:

   ```bash
   python -m http.server 5500
   ```

   Then open [http://localhost:5500](http://localhost:5500).

The featured applications are hosted separately; their demo links open those applications.

## Customize

- Edit `index.html` to update projects, education, skills, or contact details.
- Edit `style.css` to adjust colors, spacing, and layouts.
- Replace the profile photograph or résumé while keeping the filenames in `index.html` consistent.
- Check project links after changing a repository name or hosting address.

## Deployment

This portfolio can be published with **GitHub Pages**. Keep `index.html`, `style.css`, `script.js`, and the required assets in the selected publishing folder.

Follow the [official GitHub Pages setup guide](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) to configure publishing. Use the published address shown in your repository's Pages settings when sharing the website.
